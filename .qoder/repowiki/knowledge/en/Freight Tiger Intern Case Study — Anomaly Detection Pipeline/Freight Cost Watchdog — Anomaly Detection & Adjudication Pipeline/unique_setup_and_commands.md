Run via `python -m src.main`: `run [--no-llm]` executes the full deterministic or LLM-augmented pipeline writing `output/anomaly_report.csv`; `verify-sample` hard-checks the three rows of `data/sample_output_format_v2.csv`; `notes` prints parsed note facts; `ask "..."` runs the stretch Q&A. Unit tests: `pytest tests/ -q`. Eval: `python eval/run_eval.py`. Reproducibility: `python scripts/run_reproducibility.py [--llm]`. LLM config is optional — copy `.env.example` to `.env` with either OpenAI or Azure OpenAI keys; without it the pipeline runs fully deterministically.
